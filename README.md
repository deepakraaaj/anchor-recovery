# Anchor: a recovery and prevention companion

Anchor is a multimodal, GenAI-powered platform for **people navigating substance use disorders and the caregivers who support them**. It is designed for the moments when cognitive load is highest: every core flow works with **one tap or your voice. No typing needed.**

## The problem

In a craving, an overdose scare or a family crisis, people cannot search, read long pages or think of the right words. Existing resources are long, generic and text-heavy. Anchor turns Gemini into a calm, structured guide that answers in seconds, in the user's language, and always puts verified emergency help one tap away.

## Features (all live, all backed by real Gemini calls)

| Feature | What the user does | What happens |
|---|---|---|
| **Now: zero-typing interventions** | Taps a situation (craving, "I used and feel unwell", possible overdose, relapse, burnout…) and an intensity of 1–5. Caregivers can also tap overdose signs. | Gemini returns a step-by-step plan, a sentence to say aloud, a grounding exercise and what to avoid. A **deterministic safety floor** forces *emergency* mode for overdose situations or critical signs, whatever the model says. |
| **Talk: voice check-in** | Taps the mic and speaks in English, Hindi or Tamil. | The audio goes straight to Gemini (multimodal). It transcribes, reads the emotion, assesses risk, replies supportively (read aloud) and routes to the best next tool. Crisis language in the transcript escalates to a helpline. |
| **Scan: photo safety check** | Takes a photo of medicines, drinks or a room. | Gemini vision flags dangerous combinations (for example opioids or benzodiazepines with alcohol), unsafe storage and triggers, and suggests safer steps. It refuses to identify pills by appearance. |
| **Script: personalised emergency scripts** | Taps a scenario (overdose call, crisis line, telling a sponsor…). | Gemini writes a word-for-word phone script from the user's saved profile (address, medicines, conditions), with "if they ask" facts and what to do while waiting. |
| **Learn: educational resources** | Taps a topic (naloxone, dangerous withdrawals, mixing substances, caregiver boundaries…). | Gemini writes an evidence-based explainer with myths vs facts and one action for today. Responses are cached. |
| **Ride the urge** | Taps one button. | A 10-minute guided breathing (urge-surfing) timer. |
| **SOS and helplines** | Always visible. | Verified numbers for India, the US and the UK, stored in code. **They are never generated by AI.** |

Every AI answer can be **read aloud** (Web Speech API) in the selected language.

## Google GenAI services used, and where

| Service | Where in the code | Used for |
|---|---|---|
| **Gemini API** (`gemini-3.8-flash` by default, set by `GEMINI_MODEL`) through the official **`@google/genai`** SDK | [`src/gemini.js`](src/gemini.js) | Every AI feature. Uses **structured JSON output** (`responseJsonSchema`), system instructions, safety settings and a request timeout. |
| Gemini **text generation** | [`src/assistant.js`](src/assistant.js): `intervene`, `emergencyScript`, `learn` | Interventions, emergency scripts, educational explainers (EN/HI/TA). |
| Gemini **audio understanding** (multimodal) | [`src/assistant.js`](src/assistant.js): `voiceCheckIn` | Transcription, emotion and risk assessment from raw microphone audio. |
| Gemini **vision** (multimodal) | [`src/assistant.js`](src/assistant.js): `safetyScan` | Harm-reduction analysis of photos. |
| **Google Cloud Run** | [`Dockerfile`](Dockerfile) | Hosting. |

Prompts and response schemas are in [`src/prompts.js`](src/prompts.js).

## Architecture

```
Browser (vanilla JS, no build)          Node.js / Express (Cloud Run)              Google
┌────────────────────────────┐  JSON   ┌───────────────────────────────────┐      ┌──────────┐
│ Now · Talk · Scan · Script │ ──────▶ │ helmet CSP · rate limit · zod     │      │  Gemini  │
│ Learn · Me (localStorage)  │         │ routes ─▶ assistant ─▶ gemini.js  │ ───▶ │   API    │
│ Read aloud · mic · camera  │ ◀────── │ safety floor · helplines · cache  │ ◀─── │          │
└────────────────────────────┘         └───────────────────────────────────┘      └──────────┘
```

- `src/catalog.js`: the single source of truth for situations, topics, languages and helplines. The UI renders its buttons from `GET /api/options`, and the validators are built from the same lists.
- `src/schemas.js`: strict zod validation for every request.
- `src/safety.js`: deterministic rules that can only *raise* urgency or risk.
- `src/assistant.js`: feature logic. `src/gemini.js`: the model wrapper. `src/app.js`: HTTP, security and errors.

## Safety and responsible AI

- **No fake output.** If Gemini is unavailable, the API returns `503` with real helplines. The app never shows canned answers.
- **Model cannot downgrade an emergency.** Overdose situations, critical signs and crisis words in the transcript are escalated by code.
- **No hallucinated contacts.** The prompt forbids phone numbers. Helplines come from a verified list.
- **Prompt-injection hardening.** User profile text is wrapped in `<user_data>` and the model is told to treat it as data only.
- **Stigma-free, person-first language.** Short sentences for high cognitive load. No dosing advice for illicit drugs.

## Security

- Strict **Content-Security-Policy** (`script-src 'self'`, no inline scripts, `frame-ancestors 'none'`) and other Helmet headers. `Permissions-Policy` limits the microphone and camera to this site.
- Every body is checked with **zod** `.strict()` schemas: enum allow-lists, length limits, base64 and MIME allow-lists.
- **Rate limiting** on `/api`, a 7 MB body cap, `Cache-Control: no-store` on API responses.
- The API key is server-side only. No stack traces or request bodies are logged (they may contain health data).
- **Privacy by design:** the profile lives only in the browser's `localStorage`, with a one-tap "Delete all my data". Photos and audio are not stored.
- All model output is rendered with `textContent`, never `innerHTML`, so it is safe from XSS by construction.

## Efficiency

- Three runtime dependencies besides Express. No frontend framework or build step. The whole app is about 30 KB before gzip.
- An LRU + TTL cache for educational explainers. gzip compression. Static assets are cached.
- Photos are downscaled to 1280 px JPEG in the browser before upload. Audio is recorded at 32 kbps.
- Structured output with tight schemas keeps responses short. A timeout on every Gemini call.

## Accessibility

- WCAG-minded: semantic landmarks, skip link, ARIA tabs with arrow keys, `aria-live` result regions, radio and toggle roles on chips.
- Large tap targets (at least 44 px), visible focus rings, light and dark themes, `prefers-reduced-motion` support.
- Voice input and read-aloud output for people with low literacy or visual impairment. UI in English, Hindi and Tamil. `lang` updates with the chosen language.

## Run locally

```bash
cp .env.example .env          # add your GEMINI_API_KEY
npm install
npm run dev                   # http://localhost:8080
npm test                      # 26 tests (node:test + supertest)
```

## Deploy to Cloud Run

```bash
gcloud run deploy anchor --source . --region asia-south1 --allow-unauthenticated \
  --set-env-vars GEMINI_API_KEY=YOUR_KEY
```

## Testing

`npm test` runs unit tests (cache, safety rules, Gemini wrapper error handling) and API tests (validation, the emergency floor, prompt-injection wrapping, caching, rate limiting, the 503 path, security headers). Tests use an injected fake Gemini client. The running app always calls the real Gemini API.

> Anchor offers support and education. It is not a substitute for medical care. In an emergency, call your local emergency number.
